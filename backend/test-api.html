API Endpoints Documentation

Base URL: http://localhost:5001

Authentication

  • POST /api/auth/register - Register a new user
  • POST /api/auth/login - Login a user
  • GET /api/auth/me - Get current user details

Events

  • GET /api/events - Get all events
  • POST /api/events - Create an event (requires auth)
  • GET /api/events/:id - Get single event

Tickets

  • GET /api/tickets - Get all tickets (admin only)
  • POST /api/tickets - Create a ticket (requires auth)
  • GET /api/tickets/:id - Get single ticket

Payments

  • GET /api/payments - Get user payments (requires auth)
  • POST /api/payments - Process payment (requires auth)
